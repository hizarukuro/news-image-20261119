A one-image newspaper front page summing up Thursday 19 November 2026,
built as "the midnight edition" — the day that opened at midnight in
New Zealand, when GTA VI finally unlocked after a 13-year wait. The
page carries 44 stories from 6 continents: the first Trump–Xi–Putin
three-way summit at APEC in Shenzhen and its Shenzhen Declaration,
Anthropic's record $81.3bn Nasdaq debut, the World Court's Rohingya
judgment at The Hague, Cyclone Akvan bearing down on Odisha, COP31's
final 48 hours in Antalya, 551,864 students sitting South Korea's
Suneung, Israeli armour crossing Gaza's Yellow Line, a foot of rain on
Hollywood, Florida, and 28 one-line briefs — plus a day-by-hours
timeline, a numbers strip, a world map of where it happened, and a
date check that keeps out stories first reported on 18 November or
earlier. Every drawing is original flat vector-style art, typeset for
this page. Entered on make.fun (referral code c23ct4sn).

## Run it

```sh
python3 main.py
```

`main.py` copies the finished front page (`entry.png`, stored beside
it in this repository) into the output directory, byte for byte. Set
`MAKEFUN_OUTPUT_DIR` to choose the destination; without it, the image
is written to a folder named `output`. The program uses only the
Python standard library and produces identical output on every run.
