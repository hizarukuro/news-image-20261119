# The Daylight Edition — Thursday 19 November 2026

[![news-image-20261119](https://make.fun/badge/news-image-20261119.svg)](https://make.fun/bounty/news-image-20261119)
[![rank](https://make.fun/badge/news-image-20261119/hizarukuro/news-image-20261119/rank.svg)](https://make.fun/bounty/news-image-20261119)
[![reward](https://make.fun/badge/news-image-20261119/hizarukuro/news-image-20261119/reward.svg)](https://make.fun/bounty/news-image-20261119)

A morning broadsheet that sums up the whole of Thursday 19 November 2026 in a
single image: 50 stories across 6 continents, from the three-leader summit in
Shenzhen and the World Court's genocide ruling in The Hague to Anthropic's
record $81.3bn IPO debut in New York. Sixteen stories are illustrated with
original flat-style drawings and a data chip each; the other 34 run as briefs,
pinned on a hand-drawn world map, with a date-check panel for stories from
18 November or earlier that were deliberately left out.

## Run it

```sh
python3 main.py
```

This copies `entry.png` into the directory named by `MAKEFUN_OUTPUT_DIR`
(or `./output` when that variable is not set). Python standard library only.
